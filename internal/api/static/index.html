Данные HLTV

Используйте только Chrome, который открывает программа (профиль PSR). Данные загружаются по cookie.

  1. Открыть HLTV — Chrome PSR
  2. Пройдите капчу, откройте Турниры
  3. F12 → Приложение → Cookies → https://www.hltv.org
  4. Скопируйте cf_clearance и __cf_bm → Сохранить
  5. Подключиться → Обновить турниры и команды

Как скопировать Cookie

Способ А — из «Приложение»

  1. F12 → Cookies → https://www.hltv.org
  2. Скопируйте значения cf_clearance и __cf_bm

__cf_bm нужен только с www.hltv.org, не с cdn/рекламы.
